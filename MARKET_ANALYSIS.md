# Market & Competitive Landscape

## Player Metrics (Approx. Jan 2026)
- **AoE2: DE:** ~50k active ranked players. High loyalty, high "Lindy Effect."
- **AoE4:** ~60k active ranked players. Better metadata, faster parsing potential.
- **AoM: Retold:** ~30k active. "Blue Ocean" opportunity—currently lacks specialized tools.
- **StarCraft 2:** ~200k active. Highly mature tools (SC2ReplayStats), but lacks "instant" local feedback.

## User Personas
1. **The "Frustrated Intermediate" (800-1200 ELO):** Knows the build orders but forgets to execute them under pressure. Needs to know *why* their economy stalled.
2. **The "Ladder Anxious":** Plays against AI, wants to see "Ranked Readiness" scores before jumping into multiplayer.
3. **The Caster:** Needs a live efficiency overlay to explain game swings to viewers.
4. **The "Privacy-Conscious":** Wary of background apps. Needs clear proof that the tool only "sees" resource bars.

## Existing Tools (Competitors)
- **CaptureAge (AoE2):** Excellent viewer, but a "watch-back" tool for spectators, not an automated analyst for players.
- **AoE2 Insights / AoE4World:** Web-based. Requires the game to be reported to the API first (30s - 2min delay).
- **RTS Analyzer Advantage:** Zero delay. Analysis is ready before the player leaves the post-game score screen.

## Trust & Distribution Strategy
- **Security Visibility:** Feature a "Searchlight" mode that shows exactly which screen regions the OCR is looking at to build user trust.
- **EV Code Signing:** Mandatory purchase of an EV Certificate ($300-$500/year) to avoid Windows "Malicious Software" warnings during installation.
