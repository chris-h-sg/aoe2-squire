This directory contains reference data for Age of Empires II: Definitive Edition.

### Data Sources

The following resources were used to generate and normalize the CSV files in this directory:

- Unit Statistics: https://unitstatistics.com/age-of-empires2/
- Unit/Building IDs: https://airef.github.io/tables/objects.html
- Tech IDs: https://airef.github.io/tables/techs.html
- Comprehensive Data (Halfon): https://halfon.aoe2.se/
- Raw Data Source (JSON): https://github.com/SiegeEngineers/halfon/blob/master/data/units_buildings_techs.de.json

The civilization IDs are derived from the community-standard mapping used by aoe2.net / aoe2.world.
